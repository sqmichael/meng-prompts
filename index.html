30 prompts Meng To uses and teaches

Sorted by SQ Collective, by what you're trying to do. Put your own details where you see [brackets].

Start from a reference

1

Describe this reference in three terms only — flow, form and voice. Then say what I should borrow from it and what has to change.

2

Use [A] for the flow and [B] for the visual rhythm. Rebuild it for [my audience and story]. Change [one defining rule]. Keep it to one self-contained file.

3

Keep the mechanism from this reference. Change the content, the scene and the visual direction until only the structure is borrowed — then tell me what stayed and what changed.

4

Recreate this in Three.js in a single HTML file. Self-verify until perfect.

5

Analyse the attached reference and return one super prompt, not a build. Cover structure, type scale, colour, spacing, imagery, motion and tone, in that order, in prose. Obey design.md wherever it conflicts with the reference. Finish with two lists: the clauses I may change, and the ones that must stay for it to still work.

Make it move

6

Orbit using mouse.

7

Add particles to pointer.

8

Wobble using physics during mouse events.

9

Add a butterfly that flies to the branch and flies away when I mouse over it.

10

Add a scan effect to the card images while they load.

Build the page

11

Read the study and write design.md in four parts — type, colour, spacing and a small component vocabulary. Add a line to AGENTS.md telling you to read it before any change to the interface.

12

Add detailed dynamic buttons with layered hover states, pressed states, loading states, focus-visible states, icon motion, text transitions, tactile shadows, and polished micro-interactions.

13

Use Iconify Solar Duotone Bold icons.

14

Adapt page to Features page. Keep the exact same header and footer.

15

Adapt from the attached complete HTML. Keep the exact header and footer. Change the text, names and numbers. Add a framed grid layout, detailed dynamic buttons, beautiful shadows, fully responsive behaviour and Solar Duotone Bold icons. Self-verify the result.

Make it better

16

Give me two versions of this section that differ in exactly one thing: [type / colour / density]. Hold the content and the mechanism still.

17

Check this against four criteria: hierarchy, system, behaviour, responsive. Name the single largest failure, change only that, and render it again.

18

Watch the video first. Describe the motion as state, trigger, duration and response, then fold that in as a behaviour section of the prompt.

19

Rewrite the super prompt so it obeys design.md. Where the reference conflicts with my system, keep my system and tell me what you dropped.

20

Give me the same super prompt with one variable changed: [density / typography / colour logic]. Keep every other clause word for word.

Let the AI carry more of the work

21

Do this in a new thread and keep working here: [task]. Carry over design.md and the direction we already settled.

22

Summarise what this thread has settled in ten lines, then start a fresh thread from that summary.

23

Write the checks you will run before you start. Then loop until every one of them passes.

24

Run three passes at this independently, then a fourth agent to score them against the goal and keep the winner.

25

Walk sign-up, log-in and purchase in the browser as a new user would. Screenshot every step and tell me the first place it broke.

Save it, and put it on a timer

26

Turn what we just did into a skill: when to use it, what to provide, the steps, and how to check the result.

27

Read this thread and write the skill from what actually worked, not from what I asked for first.

28

Name the trigger so you would reach for this on your own next time. Show me the trigger line and nothing else.

29

Every week: one page on what shipped, what broke and what is still open. No adjectives.

30

Every 24 hours: walk the site page by page — sign-up, log-in, purchase, browse, courses, tutorials. Check each page loads, each form submits and each link resolves. Report only what broke, with the URL and the step it failed on.
